# Muer Spring Boot Starter

`muer-spring-boot-starter` is intentionally a dependency-only Spring Boot starter. It aggregates Muer auto-configuration and the Spring Boot dependencies required by consuming applications, but it does not expose its own public Java API.

The public auto-configuration API is provided by `muer-spring-boot-autoconfigure`.

This placeholder document is packaged as the module's `-javadoc.jar` so Maven Central receives the required documentation artifact without introducing artificial public marker classes solely for Javadoc generation.
